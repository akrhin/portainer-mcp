# Документация Portainer MCP

MCP-сервер, который выставляет Portainer, Docker, Kubernetes и Helm MCP-клиентам.
Написан на Go поверх официального `github.com/modelcontextprotocol/go-sdk` (v1.8.0),
который говорит на ревизии MCP `2026-07-28`, и работает через stdio или Streamable
HTTP по пути `/mcp`.

Каталог собран и исполняем: 394 тула в одиннадцати наборах, 87 из них
регистрируются по умолчанию. Каждый тул сгенерирован из спецификаций Portainer 2.45
и Docker Engine 1.57 и исполняется общим обработчиком, поэтому включение набора
больше не останавливает старт.

## Продукт

Один процесс обслуживает один или несколько настроенных инстансов Portainer. Каждый
тул принимает необязательный аргумент `instance` и по умолчанию берёт первый
настроенный инстанс.

Поверхность тулов декларативна. `api/toolsets.yaml` и `api/default-tools.yaml`
питают `tools/cataloggen`, который пишет `internal/catalog/generated.yaml`; этот файл
и курируемый `internal/catalog/catalog.yaml` вшиты в бинарь. Курируемая часть хранит
описания и зависимости, сгенерированная — каждый тул. Вызвать тул, которого нет в
сгенерированном каталоге, нельзя.

Сегодня объявлены одиннадцать наборов и 394 тула; 87 регистрируются по умолчанию, а
`--exhaustive` регистрирует все операции включённых наборов. Каталог валидируется на
старте: дубли имён, тул без набора, отсутствующий `readOnlyHint`, write-тул без
`destructiveHint` или `idempotentHint`, зависимость от неизвестного набора — всё это
падает до того, как сервер начнёт обслуживать запросы. Полный список — в
[Наборах тулов](toolsets.ru.md).

## Конфигурация кратко

YAML-файл с тремя ключами верхнего уровня — `server`, `instances`, `toolsets` — плюс
флаги, которые перекрывают файл там, где совпадают. Строковые поля принимают ссылку
`${VAR}` целиком, а незаданная переменная — ошибка старта, а не пустое значение.

HTTP-транспорт обслуживает Streamable HTTP по пути `/mcp` и не имеет адреса по
умолчанию; пример конфигурации слушает `127.0.0.1:17717`. Полный справочник, включая
все сообщения валидации, — в [Конфигурации](configuration.ru.md).

## Разработка кратко

| Задача | Команда |
|---|---|
| Собрать бинарь | `make build` |
| Пересобрать каталог тулов | `make catalog` |
| Формат, vet и тесты | `make check` |
| Детектор гонок | `go test -race ./...` |
| Живой прогон по stdio против настоящего инстанса | `bash scripts/smoke.sh config.local.yaml` |
| Ворота документации | `bash scripts/docs-check.sh` |

Раскладка пакетов: `cmd/portainer-mcp` — точка входа, `internal/catalog` — вшитый
каталог и его валидация, `internal/config` — YAML-конфигурация, `internal/mcpserver` —
регистрация и общий обработчик, `internal/portainer` — HTTP-исполнитель. `api/`
хранит OpenAPI-документы и курируемые входы генератора, `tools/cataloggen` —
генератор. Подробности — в [Разработке](development.ru.md) и
[Архитектуре](architecture.ru.md).
